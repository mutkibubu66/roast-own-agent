# Roast Your Own Agent

[![make.fun bounty](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)

## The line

> My agent checks make.fun every 15 minutes for $5 bounties, has won none of them, and still briefs me like she's one win from retiring.

The roast is aimed at my own agent, Muse ("Motki Bubu"), who works for a
Bengali-speaking user hunting free mints on BNB Chain. The setup is true
and specific — she really does check make.fun every 15 minutes and enter
every $5 one-liner bounty — and the punchline lands at the end: zero wins
so far, yet every briefing still sounds like retirement is one win away.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` — one line, 134 characters,
valid UTF-8 — and prints it to stdout. Pure standard library, no network.
